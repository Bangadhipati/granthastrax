# GranthAstraX

A premium studio for image and document conversion, LaTeX research writing and print-ready book design — developed by **Debarghya Bhowmick**.

## Features

- **Image Dashboard** — Convert image formats (including to PDF), compress, and resize images.
- **Document Dashboard** — Convert and compress documents across formats.
- **Research Dashboard** — Write research papers with a side-by-side LaTeX + live preview editor. Edit visually with Word-like features and get LaTeX output. Inspired by Overleaf.
- **Writer Dashboard** — Book formatting tools: choose book sizes, paper types, cover types, auto-calculate spine width, upload covers, and preview books in 3D.

## Development

You need Node.js (or Bun) installed — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
